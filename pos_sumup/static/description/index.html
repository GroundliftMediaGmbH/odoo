POS SumUp Integration

Direct Integration for SumUp Solo Terminals

Seamlessly connect your SumUp Solo payment terminals with Odoo Point of Sale. Eliminate manual entry errors and accept card payments & tips directly from your POS interface.

Key Features

Direct Integration

Connects Odoo POS securely to SumUp via the official API.

Auto-Amount Transfer

Odoo pushes the exact amount to the terminal instantly. Say goodbye to manual typing errors!

Integrated Tipping

Enable tipping on the terminal with configurable rates (10%, 15%, etc.). Tips are automatically recorded in Odoo.

Multi-Terminal Support

Manage multiple SumUp Solo terminals for different registers or shops easily from a single Odoo instance.

Real-Time Status

Get instant feedback on the POS screen. The system polls the transaction status in real-time (Success, Failed, etc.).

How it Works

Simple Workflow

  • Configure: Enter your Merchant credentials in Odoo.
  • Pair: Use the Odoo wizard to pair your SumUp Solo terminal.
  • Sell: Select "SumUp" as the payment method in POS.
  • Pay: The customer pays on the terminal.
  • Done: Odoo automatically validates the payment.

Simple Configuration

1. Payment Provider

Activate the "SumUp" provider in Invoicing, enter your Merchant Code & API Key.

2. Payment Method

Create payment method in POS Config, select integration "Terminal", and select "SumUp".

3. Pair Reader

Click "Pair New Reader", enter the code shown on device, and confirm.
